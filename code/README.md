# code

The original dissertation R Markdown that the forecasting app grew out of.

`MD3 Forecast trend jackets Aut.Rmd` walks through pulling Google Trends data
with `gtrendsR`, forecasting it with Prophet, getting daily granularity out of
`trendecon`, and comparing the result against ARIMA and ETS.

It is kept as a write-up. The maintained, interactive version of the same idea
is [`../Forecasting-trends`](../Forecasting-trends).
